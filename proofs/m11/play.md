# Play locally (M11)

One-time setup: `npm install`. RAA comes from the `@etcito/raa` release, so there is no RAA build step.

Run `npm run play` and open http://localhost:5173/game.html.

Move with WASD (or ZQSD) or the arrow keys; Space jumps, Shift dives, and E grabs. The mouse turns the view.

Add `?course=<id>` to play one course with bots, for example `?course=race-sprint`.
